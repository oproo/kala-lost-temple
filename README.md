# KĀLA: The Lost Temple

A small browser arcade RPG prototype.

## Run locally
Open `index.html` in a modern browser.

## Host with GitHub Pages
1. Create a GitHub repository named `kala-lost-temple`.
2. Upload `index.html`, `style.css`, `game.js`, and the `assets` folder.
3. In GitHub, open Settings → Pages.
4. Set the source to the `main` branch and `/ (root)`.
5. Save. GitHub will provide the public game URL.

## Controls
Desktop:
- WASD / Arrow keys: move
- Space: attack
- Shift: dash
- E: interact
- Esc: pause
- R: restart after defeat

Mobile:
- On-screen movement, attack, dash, and interact buttons.
